# merkle-bplustree

merkle-bplustree provides an implementation of a [B+Tree](https://en.wikipedia.org/wiki/B%2B_tree) that utilises
Merkle Trees for nodes, providing efficient proofs.

The crate is designed for out-of-memory storage, and provides async-enabled storage traits to do so.
This crate also allows you to configure almost everything about the tree, including the hasher and shape constraints.
